# Dessert Verkoop

Website om dessertverkoop te noteren (aantal, cash/bank) met live totalen en grafieken. Bedoeld om te delen via Netlify; data staat in een Google Sheet.

- `index.html` — verkoop invoeren
- `dashboard.html` — KPI's + grafieken + volledige transactielijst
- `google-apps-script/Code.gs` — backend die je in je Google Sheet plakt
- `HANDLEIDING.md` — stap-voor-stap opzet (Google Sheets + Netlify + GitHub)

Gebruik: volg `HANDLEIDING.md`. Technisch: statische HTML/CSS/JS + Chart.js, geen build-stap.
